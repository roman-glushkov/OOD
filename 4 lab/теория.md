## 🎯 Что улучшилось

### 1. Архитектура файлов

- Файлы разложены **по слоям**: `core`, `adapter`, `shapes`, `io`, `editor`, `utils`
- Понятно, где что лежит, легко навигировать
- Соответствует принципам **SOLID** на уровне файловой системы

### 2. Паттерн Composite

- Реализована группа фигур `CompositeShape`, которая **сама является фигурой** (`IShape`)
- С группой можно делать всё то же, что с одиночной фигурой: рисовать, выделять, двигать, считать площадь
- Группировка (`Ctrl+G`) и разгруппировка (`Ctrl+U`) работают через Composite

### 3. Интерактивность

- **Выделение** фигуры кликом мыши через `Contains()`
- **Множественное выделение** через `Shift + ЛКМ`
- **Drag-and-drop** — перемещение выделенных фигур или группы
- **Визуальная индикация** выделения: зелёная обводка + увеличенная толщина

### 4. Разделение ответственности

- `Editor` хранит **своё состояние** (`m_selected`, `m_dragging`, `m_lastMouse`) внутри
- Методы `Editor` не требуют длинных сигнатур — `HandleMousePressed(mouse)` вместо 6 параметров
- `main.cpp` стал **чистым оркестратором**: загрузить → вывести → запустить редактор

### 5. Централизация констант

- Все "магические числа" вынесены в `Config.h`
- Легко менять поведение программы в одном месте
- Код стал **самодокументируемым** — `Config::MIN_SHAPES_FOR_GROUP` понятнее, чем `2`

## 📊 Использованные паттерны

| Паттерн             | Где                                           |
| ------------------- | --------------------------------------------- |
| **Adapter**         | `ShapeAdapter<T>` над SFML-классами           |
| **Factory**         | `ShapeFactory::Create()`                      |
| **Template Method** | `IShape::ToString()` (через `ShapeFormatter`) |
| **Composite**       | `CompositeShape` для групп                    |
| **Polymorphism**    | `vector<unique_ptr<IShape>>`                  |
| **RAII**            | `unique_ptr` для управления памятью           |

## 🎤 Тезисы для защиты

1. **Adapter:** `ShapeAdapter<T>` адаптирует SFML-классы под интерфейс `IShape`, не наследуясь от них
2. **Composite:** `CompositeShape` реализует паттерн Composite — группа тоже фигура, что даёт единообразную работу с одиночными фигурами и группами
3. **Разделение ответственности:** `Editor` отвечает за интерактивность, `main` — за оркестрацию
4. **HitTest:** геометрические проверки вынесены в отдельный namespace для переиспользования и тестируемости
5. **Централизация:** все константы в `Config.h`, цвета — в `Colors.h`
6. **Структура:** файлы разложены по слоям архитектуры (`core`, `adapter`, `shapes`, `io`, `editor`, `utils`)
