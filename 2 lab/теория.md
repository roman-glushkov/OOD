# Выделение фигур — что и где изменено

## `include/IShape.h`

Добавлены два чистых виртуальных метода:

| Метод         | Назначение                   |
| ------------- | ---------------------------- |
| `Contains`    | попадание точки в фигуру     |
| `SetSelected` | включить/выключить подсветку |

## `include/ShapeAdapter.h`

Вся логика выделения — один раз для всех фигур:

```cpp
void SetSelected(bool selected) override {
    if (selected) {
        m_shape.setOutlineColor(ShapeColors::SelectedOutline());
        m_shape.setOutlineThickness(
            ShapeColors::OutlineThickness() * Config::SELECTED_THICKNESS_FACTOR);
    } else {
        m_shape.setOutlineColor(GetDefaultOutlineColor());
        m_shape.setOutlineThickness(ShapeColors::OutlineThickness());
    }
}
```

Добавлен новый чисто виртуальный метод:

```cpp
virtual sf::Color GetDefaultOutlineColor() const = 0;
```

## `src/main.cpp`

Раньше тут была одна выбранная фигура:

```cpp
IShape* selected = nullptr;
```

Теперь — **список** выделенных, чтобы работал Shift + клик:

```cpp
std::vector<IShape*> selected;
```

Добавлены три маленьких лямбда-хелпера:

```cpp
auto isSelected = [&](IShape* shape) {
    return std::find(selected.begin(), selected.end(), shape) != selected.end();
};

auto selectOne = [&](IShape* shape) {
    if (!shape || isSelected(shape)) return;
    shape->SetSelected(true);
    selected.push_back(shape);
};

auto deselectOne = [&](IShape* shape) {
    shape->SetSelected(false);
    selected.erase(
        std::remove(selected.begin(), selected.end(), shape),
        selected.end());
};

auto clearSelection = [&]() {
    for (IShape* s : selected) {
        s->SetSelected(false);
    }
    selected.clear();
};
```

**При клике** — ищем верхнюю фигуру под курсором, смотрим, зажат ли Shift:

```cpp
IShape* hit = nullptr;
for (auto it = shapes.rbegin(); it != shapes.rend(); ++it) {
    if ((*it)->Contains(pos)) {
        hit = it->get();
        break;
    }
}

bool shift = sf::Keyboard::isKeyPressed(sf::Keyboard::Key::LShift)
          || sf::Keyboard::isKeyPressed(sf::Keyboard::Key::RShift);

if (shift) {
    if (hit) {
        if (isSelected(hit)) deselectOne(hit);
        else                selectOne(hit);
    }
} else {
    clearSelection();
    if (hit) selectOne(hit);
}
```

- **Left Click** — сбрасывает всё и выделяет одну фигуру под курсором (или ничего, если клик в пустоту).
- **Shift + Left Click** — добавляет/убирает фигуру под курсором в набор (toggle). Клик в пустоту при Shift ничего не делает.

**При отрисовке** — цикл стал проще: подсветка уже включена/выключена в момент клика через `SetSelected`, поэтому здесь её переключать не нужно.

```cpp
for (const auto& shape : shapes) {
    shape->Draw(window);
}
```

Как это работает (коротко)
Клик по фигуре:

main перебирает shapes с конца, зовёт Contains. У CompositeShape Contains возвращает true, если попал в любого ребёнка. То есть для main группа — это просто фигура.

Shift+клик:

То же самое, но toggle выделения. Если попал в CompositeShape — выделяется вся группа сразу, потому что CompositeShape::SetSelected вызывает SetSelected у всех детей.

Ctrl+G:

Берём выделенные unique_ptr из shapes, кладём в новый CompositeShape, возвращаем CompositeShape обратно в shapes.

Ctrl+U:

Ищем выделенный CompositeShape (через dynamic_cast), забираем детей через Release(), кладём их обратно в shapes, удаляем сам CompositeShape.

Отрисовка:

Просто shape->Draw(window). Для CompositeShape это цикл по детям.
