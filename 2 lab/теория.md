Composite: CompositeShape реализует паттерн Composite — группа тоже является фигурой, что позволяет единообразно работать с одиночными фигурами и их группами.

Adapter: ShapeAdapter<T> остаётся адаптером над SFML-классами. Логика выделения и движения — общая, специфика — в наследниках.

HitTest: проверки попадания вынесены в отдельный namespace для переиспользования и тестируемости.

Selection: main.cpp хранит вектор указателей на выделенные фигуры. Через SetSelected(true) они получают зелёную обводку.

Group: при Ctrl+G фигуры перемещаются из общего списка в CompositeShape, который сам становится элементом списка. При Ctrl+U — наоборот.

Drag-and-drop: при MouseMoved вычисляется смещение и вызывается Move(dx, dy) для всех выделенных фигур (или группы).

Полиморфизм: main работает только с IShape\*, не зная конкретных классов.
