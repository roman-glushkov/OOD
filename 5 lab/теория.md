## Как работает Undo/Redo

```
Save(memento)   — перед действием кладём снимок «до» в undoStack, redoStack очищается

Undo(current)   — берём «до» из undoStack,
                  текущее («после») кладём в redoStack,
                  восстанавливаем «до»

Redo(current)   — берём «после» из redoStack,
                  текущее («до») кладём в undoStack,
                  восстанавливаем «после»
```

## Когда делается снимок

| Действие                     | Снимок                                                 |
| ---------------------------- | ------------------------------------------------------ |
| Клик по фигуре (выделение)   | **нет**                                                |
| Клик по пустому месту        | **нет**                                                |
| Драг без движения            | **нет** (снимок создан, но выброшен)                   |
| Драг с движением             | **да**                                                 |
| Добавление фигуры            | **да**                                                 |
| Цвет / толщина               | **да**                                                 |
| Группировка / разгруппировка | **нет** (вызываются из `Application`, минуя `Toolbar`) |
